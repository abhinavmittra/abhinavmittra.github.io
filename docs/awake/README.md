# A•WAKE

`public/cold-brew/awake-mood-board.png` is the supplied brand source. Its SHA-256 is `f1151961322b6bf67eef5b97ff16b394c05aa20fda9f988a0202134b5e8d00c1`. `content/cold-brew.ts` defines the logo crop; the interface and procedural flask reuse those pixels.

The palette uses paper `#f2eee4`, olive `#39471f`, sand `#efd594` and periwinkle `#7d89d9`. The three supplied taglines are defined in `content/cold-brew.ts` and used sparingly on labels and the product page.

The back-label image is a visual mockup, not evidence of certification, shelf life or a live batch number. Those details are not product facts. Product copy, prices and the WhatsApp handoff have one source in `content/cold-brew.ts`.
